# POINT-AND-WATCH — the brief ("show, don't explain")
## Claude Code session, branch queen-watch off queen-v1. Same laws.
## Mission: the keeper points her at a REAL thing and WATCHES verification
## happen in the browser. Zero terminal ceremony after launch.

## W1 — `dotmaps watch <url>` + the door learns to accept a target
Hive Door gains one input: "Point me at something" (URL for v0).
Backend: compile a HEALTH MAP for the target — v0 predicate set,
derived not hardcoded: every internal link resolves (crawl 1 level),
each page returns 200, page title non-empty, forms present respond to
GET, declared assets load. Each = a dot with a mechanical check
(HTTP/DOM — this IS a real oracle; no model needed to verify).
Preset shipped: bensluzasgolf.com.
DONE-TEST: watch on a local test site yields a map with >=8 dots.

## W2 — Live verification theater (the point of everything)
On submit: the map renders as a dot constellation in the Hive
(unlit). Checks execute server-side one by one; each dot LIGHTS —
green verified / red failed / amber unreachable — streaming via SSE
or 1s polling, ~2 dots/sec so the eye can follow. Diary narrates in
plain words as it goes ("Checked the booking page — responds ✓").
Failures produce a real ESCALATE card with the evidence receipt.
Then: a RE-WATCH toggle — re-verify every N minutes; dots re-light,
diary appends only on CHANGES (silence = health, per her law).
DONE-TEST: sabotage one page on the local test site mid-watch → its
dot flips red on next cycle + escalate appears with the receipt.

## W3 — Certify what holds (the metabolism touches the real world)
A dot that verifies clean across >=20 consecutive checks earns a real
certificate (existing certify path, Wilson bound over the check
history) and its honeycomb cell fills gold: the first certified
skills about a REAL domain. Trips: CERTIFIED emitted, chain intact.
DONE-TEST: fast-clock the cycle in test → cell fills, certificate
present, assure still green (extend claim list with watch-oracle row).

## Hard laws for this build
No model calls anywhere in the watch loop (mechanical oracle only —
that's the demonstration). Zero jargon on screen. All state in the
existing files (trips.jsonl, skills/). No push; commit per gate.
