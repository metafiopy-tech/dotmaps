The biology, and the build

Each piece below is a documented property of human memory (left, with the science) mapped to an engineerable mechanism (right). Together they're one system.

You don't store memories — you regrow themreconstructive memory · Bartlett 1932
Seeds, not photocopies. Keep the gist + key facts + a pointer into the diary. Regenerate the full memory on demand. Storage collapses ~10×.
Your regrown memories can be wrongfalse memory · Loftus
So every regrowth gets fact-checked. Hard facts must match an append-only diary exactly; structure must be consistent with it; only connective tissue regenerates freely. The system cannot "remember" what the diary doesn't contain.
Recalling a memory rewrites itreconsolidation · Nader, Schafe & LeDoux 2000
Recall is a write. Every use updates the seed, resets its decay clock, and logs the change. Memory becomes shaped by its own usage history — with an audit trail biology never had.
You forget most things — on purposeforgetting curve · Ebbinghaus
Forgetting is the filter. Unused memories fade back to seeds on a spaced-repetition clock. What survives repeated fading is, by definition, what keeps proving useful. Selection, not loss.
Practice hardens skills into reflexesconsolidation · systems-level
Verified patterns crystallize. A memory that keeps passing its fact-checks crosses a threshold and hardens into an instant, near-free artifact. The threshold moves only on external verification — never on the system's own confidence.
Old habits break when the world changes — or shouldthe failure is called dogma
Crystals can melt. Every hardened artifact carries a fingerprint of the conditions it formed under. When the world drifts from that fingerprint, it demotes itself back to "re-learn me." No calcification.
Sleep consolidates the daycomplementary learning systems · McClelland 1995
A nightly cycle compresses the day's episodes into durable gist, discards noise, and promotes/demotes across the layers. Fast clock, medium clock, slow clock — deliberately never in lockstep.
You know things by predicting thempredictive coding · surprise as signal
Grounding that scales with time. The system predicts its next input; surprise is free error signal. External reality — not internal coherence — is the only thing allowed to move any threshold.
the one-line thesis

When generation is cheap, the scarce function is deciding what's real.

A generator can produce anything — including fluent, confident false memories. The entire proposal reduces to wiring generation to three disciplines: a diary it can't edit (provenance), tests it can't sweet-talk (external verification), and a clock it can't ignore (decay, reconsolidation, annealing). That's not a storage upgrade. That's a metabolism.

Status, honestly: this is a public proposal with working parts, not a finished product. Already built & tested in the open: the fact-checking ladder, the decay engine, and crystallization-by-external-test (a skill-certification system that survived 52 pre-registered runs — including the claim that died and was published anyway). The genuinely new piece — recall-that-rewrites — is specced and small. The first falsification test is pre-registered: compress real memories to seeds, delete the originals, regrow on demand, and measure fidelity against the diary. If it fails, that gets published too.
