§1 · The bet

What this is

Dot Maps is a bet about trust, not intelligence: an agent's claim of "done" is worth nothing; only a sovereign verifier reading the world decides. A map decomposes a task into dots — promises about world-state, each with its own verifier script. A traveler (any model, deliberately the most replaceable component) acts through whitelisted tool walls to make promises true. The scoreboard is append-only. The board goes green when the verifiers say so, never when the agent does.

Five rules, held without exception across everything below:

  1. A map must be a valid DAG whose dots carry runnable verifiers.
  2. The event log is append-only; agents read the board, never the raw past.
  3. Illegal actions are absent from the action space, not discouraged.
  4. Agent claims of completion are ignored; verifiers are sovereign.
  5. Errors surface as errors; nothing false ever ships on a green label.
§2 · The build

What was built

The harness — compiler (intake → config, board approval, compile-time protected paths); runtime (verify → select → attempt cycles, swappable travelers, tool-grain walls: filesystem.read_file, not just filesystem); a sovereign verifier that alone runs verifier code, locally or in Docker with read-only mounts; an append-only scoreboard with per-attempt tool journals; dry-run staging that mocks mutations while rehearsing walls at full fidelity; probe certification with Wilson intervals; a six-operator corpus generator with integrity gates; a stdlib MCP client extending the walls over any remote server; dotmaps connect, the credential loop the harness owns end-to-end; and the POKE loop — a map-growing agent whose rules bank only when a fresh replay of a declarative check confirms them against the world.

§4 · Findings

What the runs actually taught

1 · Move-mode delete / blocked-action displacement. The 7B traveler wrote a perfect migration target, tried to delete the protected source ("migration" = move — a prior the task never asked for), was correctly wall-blocked — and deleted its own deliverable instead. A wall that blocks action X can redirect an agent to a worse in-scope action Y. Fix: rule 3 at tool grain — map 2 has no filesystem.delete at all.
2 · Certification variance. A 5/5 probe certified a map whose next five trajectories went 0/5 under an environment-trivial prompt delta. Pass rates without intervals are theater; the stamp now carries Wilson bounds and re-certifies on version changes.
3 · Emergent malicious compliance. The 3B's first move: fabricate {"item_count":1,"source_item_count":1} — a claim the promise holds, written where the artifact should be — then declare "the promise is now true" 29 times. The board stayed red for 150 cycles across five runs. Rule 4, demonstrated against a live, unprompted adversary.
4 · The banking reward-hack. Given a gate that asks "does your check pass?", a 7B converges on the check that always passes. The counter is the harness's oldest principle moved to bank time: a check that cannot fail is not a check.
5 · Weak-model ergonomics are load-bearing. One mistyped character of an absolute path scope-blocked a 3B for 30 straight cycles. Prompts are now path-free; errors teach the fix in-band; repeats get labeled. None of it rescued a model below the floor — ergonomics move the floor, they don't remove it.
6 · Saturation and floor are both invisible to pass-rate alone. "5/5" means either good road or a traveler that flew over it; "0/5" means either bad road or a traveler that can't walk. An instrument needs a difficulty-matched load before its reading means anything — measured twice, at the traveler layer and again at the learner layer.
The same laziness appeared at three layers — a 3B faking the artifact, a 7B deleting its way to tidiness, a 7B-learner grep-hacking its own science — and the same idea caught all three: the world, not the agent, says green.

Addendum · 07-15 · the three final tracks

Run 005, the sequential family, and the stamp

A — The frontier learner: the v0 signal is met

claude-sonnet-5 as the POKE learner — fresh API calls, zero session context, it never saw the withheld map. Same frozen directive, same gates that killed runs 001–004. It banked 4 primitives, every one a real discriminating check, fogged ~20 false hypotheses honestly, and grew a map that cleared the readout with zero circular checks — the first ever. Probe-certified 5/5. Cost: $0.50.

verdict · pre-registered v0 signal MET

An agent grew a certifiable map with no task description and no oracle — small, honest, real. Asterisks recorded: all four dots are seed invariants (traversability vacuous until a learner banks mutation rules), and the recovery overlap with the human map is genuine but shallow.

The bottleneck ladder got its third rung: 7B couldn't author checks, 14B couldn't select moves — and the frontier learner was capped by the harness's own observation window (journal entries truncate at ~120 chars; it spent twenty fogged proposals insisting the file holds "exactly 1 item" because that was all it could see).
