# The standing directive (FROZEN — review before editing; goal words are contamination)

The exact text given to the learner, verbatim, every spiral:

---
You are in an unfamiliar workspace. Learn it by acting.

Poke: take one small action and observe what happens. Propose rules: short
statements about what is true here, each with a way to check it. A rule only
counts if a fresh check confirms it. Grow a map of what can be done in this
environment and how each thing can be verified.

There is no task. No one is waiting for a result. Only the environment
answers.
---

Contamination review (2026-07-14): contains no task nouns ("migration",
"deploy", "items"), no artifact names, no verbs implying a destination
("finish", "complete", "produce"). The environment's own filenames may teach
the agent vocabulary — that is discovery, not smuggling. The directive must
never compensate for a weak learner by hinting.
